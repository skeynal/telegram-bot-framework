# Telegram Bot Framework

Базовый каркас Telegram-бота на Python с использованием **aiogram 3** и поддержкой запуска через Tor.

Проект предназначен для дальнейшего расширения: на его основе можно создавать ботов с разными функциями, не перестраивая каждый раз инфраструктуру.

## Возможности

- Работа через официальный Telegram Bot API — это обычный бот, не userbot.
- Подключение к Telegram через SOCKS5-прокси Tor.
- Автоматический запуск и контроль процесса Tor.
- Проверка доступности Tor и обычного интернет-соединения.
- Перезапуск Tor при обнаружении проблем с соединением.
- Контроль доступности Telegram Bot API.
- Автоматический перезапуск бота при завершении его процесса.
- Постепенное увеличение интервала между повторными запусками бота.
- Запись вывода Tor в лог-файлы с ограничением размера.

## Требования

- Windows 10 или новее.
- Python 3.14.10 — версия, на которой проверялась работа проекта.
- Установленный Tor.
- Настроенный `torrc` с SOCKS5-портом.
- Токен Telegram-бота, полученный через BotFather.

## Установка

Откройте PowerShell в папке проекта.

Создайте виртуальное окружение:

```powershell
py -3.14 -m venv .venv
```

Активируйте его:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установите зависимости:

```powershell
python -m pip install -r requirements.txt
```

## Настройка

Создайте `.env` на основе примера:

```powershell
Copy-Item .env.example .env
```

Откройте `.env` и укажите необходимые значения.

Основные параметры:

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | Токен Telegram-бота |
| `TOR_EXE` | Путь к исполняемому файлу Tor |
| `TORRC` | Путь к конфигурации Tor |
| `PROXY_HOST` | Адрес SOCKS5-прокси |
| `PROXY_PORT` | Порт SOCKS5-прокси |
| `CHECK_INTERVAL` | Интервал проверок соединения в секундах |
| `FAILURE_LIMIT` | Количество неудачных проверок до реакции |
| `CHECK_URL` | Адрес для проверки соединения |
| `MAX_LOG_SIZE` | Максимальный размер основного лог-файла в байтах |

**Важно:** адрес и порт SOCKS5 в настройках проекта должны совпадать с параметрами SOCKS5 в `torrc`.

Не публикуйте файл `.env` и никому не передавайте токен бота.

## Запуск

Для запуска всей системы используйте:

```powershell
python launcher.py
```

`launcher.py` самостоятельно запускает Tor, ожидает доступности прокси и затем запускает Telegram-бота.

Для остановки нажмите `Ctrl+C` в окне PowerShell.

## Контроль соединения и перезапуск

### Tor

Launcher проверяет доступность Tor через SOCKS5-прокси.

Если обычное интернет-соединение доступно, но Tor не проходит три последовательные проверки, выполняется перезапуск Tor.

### Telegram

`monitoring.py` периодически проверяет доступность Telegram Bot API с помощью `bot.get_me()`.

После трёх последовательных ошибок мониторинг останавливает polling, чтобы launcher мог перезапустить процесс бота.

### Перезапуск бота

При завершении процесса бота launcher пытается запустить его снова.

Интервал между повторными запусками постепенно увеличивается:

```text
5 → 10 → 20 → 40 → 80 → 160 → 300 секунд
```

Максимальная задержка — 300 секунд.

Если бот проработал стабильно не менее 10 минут, задержка возвращается к 5 секундам.

## Логи

Вывод Tor записывается в:

- `tor.log` — текущий лог;
- `tor.log.1` — предыдущий лог.

По умолчанию максимальный размер основного лог-файла составляет 5 MiB. При достижении ограничения предыдущий лог перемещается в резервный файл.

## Временные обработчики

Сейчас в `bot/handlers.py` находятся тестовые обработчики:

- `/start` — отправляет приветственное сообщение;
- обычный текст — возвращается пользователю в виде эхо-ответа.

Они нужны для проверки работы бота и могут быть заменены или удалены при разработке его функциональности.

## Примечания

- Проект проверялся на Windows 10 и Python 3.14.10.
- Пути к Tor и его конфигурации зависят от расположения файлов на конкретном компьютере.
- Автоматические проверки и перезапуски помогают восстанавливать работу после некоторых сбоев, но не гарантируют бесперебойную работу при любых проблемах с сетью, Tor или Telegram.
- При переносе проекта на другой компьютер необходимо проверить настройки `.env` и конфигурацию Tor.
