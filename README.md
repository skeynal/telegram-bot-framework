# Telegram Bot Framework

Базовый каркас Telegram-бота на Python с использованием **aiogram 3** и поддержкой запуска через Tor.

Проект предназначен для дальнейшего расширения: на его основе можно создавать ботов с разными функциями, не перестраивая каждый раз инфраструктуру.

## Возможности

- Работа через официальный Telegram Bot API — это обычный бот, не userbot.
- Подключение к Telegram через SOCKS5-прокси Tor.
- Автоматический запуск и контроль процесса Tor.
- Проверка доступности Tor и обычного интернет-соединения.
- Перезапуск Tor при обнаружении проблем с соединением.
- Контроль доступности Telegram Bot API.
- Автоматический перезапуск бота при завершении его процесса.
- Постепенное увеличение интервала между повторными запусками бота.
- Запись вывода Tor в лог-файлы с ограничением размера.

### Назначение файлов

| Файл | Назначение |
|---|---|
| `launcher.py` | Запуск и контроль Tor и Telegram-бота |
| `main.py` | Основная точка входа бота |
| `bot/handlers.py` | Обработчики сообщений Telegram |
| `monitoring.py` | Проверка доступности Telegram Bot API |
| `proxy.py` | Создание SOCKS5-сессии для aiogram |
| `config.py` | Загрузка и проверка токена бота |
| `settings.py` | Настройки путей, прокси, проверок и логов |
| `requirements.txt` | Список Python-зависимостей |
| `.env.example` | Пример файла с настройками |
| `.gitignore` | Исключение служебных файлов и секретов из Git |

## Требования

- Windows 10 или новее.
- Python 3.14.10 — версия, на которой проверялась работа проекта.
- Установленный Tor.
- Настроенный `torrc` с SOCKS5-портом.
- Токен Telegram-бота, полученный через BotFather.

## Установка

Откройте PowerShell в папке проекта.

Создайте виртуальное окружение:

```powershell
py -3.14 -m venv .venv
```

Активируйте его:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установите зависимости:

```powershell
python -m pip install -r requirements.txt
```

## Настройка

```powershell
Copy-Item .env.example .env
```
